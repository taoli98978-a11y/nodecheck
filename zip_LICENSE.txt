WHAT THIS DATA IS, AND IS NOT

  A ZIP code is a set of mail routes, not an area. The Census Bureau
  approximates most of them with ZIP Code Tabulation Areas (ZCTAs); the
  population and areas here describe the ZCTA. ZIP codes with no ZCTA
  (PO-box-only, single-organisation and military codes) have those fields
  EMPTY. Empty means not measured. It never means zero.
