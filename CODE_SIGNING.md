# Code signing policy

Status: preparing an application for free open-source code signing; NOT approved by SignPath Foundation.
No current build is represented as signed by SignPath or as trusted by Windows Smart App Control.

Repository owner, maintainer, reviewer and proposed release approver: @taoli98978-a11y.
Only artifacts built from the reviewed source in this repository are eligible for a future signing request.
Every signing request must be manually approved by the maintainer. Private keys and proxy credentials must never be committed.
Maintainers must enable multi-factor authentication before enrolling in a signing service.

If approved, this policy will be updated with the actual signing provider, attribution and configured build workflow.
See PRIVACY.md and THIRD_PARTY.txt for data handling and dependencies.
